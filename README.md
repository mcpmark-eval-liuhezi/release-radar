# Release Radar

Release Radar is a small, open-source workspace where we keep notes on the releases of the upstream projects we depend on. Monitors upstream releases and records them as they ship.

## Monitored projects

- [facebook/react](https://github.com/facebook/react) — UI library we build on

The full list, together with the latest release we have on record for each project, lives in [docs/monitored-projects.md](docs/monitored-projects.md).

## Contributing

Work on a branch, keep commits small, and open a pull request against `main`. See [docs/onboarding.md](docs/onboarding.md) for the contributor walkthrough (coming soon).
